# Recherche Flo

## Heatmaps
Heatmaps sind eine Form der Datenvisualisierung, die verwendet wird, um die Dichte oder Intensität von Datenpunkten in einem zweidimensionalen Raum darzustellen. Sie verwenden Farbcodierung, um die Werte in einer Matrix oder einem Raster zu repräsentieren, wobei unterschiedliche Farben unterschiedliche Wertebereiche anzeigen.

### Matplotlib
Matplotlib ist eine weit verbreitete Bibliothek in Python zur Erstellung von statischen, animierten und interaktiven Visualisierungen. Sie bietet umfangreiche Funktionen zur Erstellung von Heatmaps durch die Verwendung von Funktionen wie `imshow()` oder `pcolormesh()`, die es ermöglichen, Daten in einem Rasterformat darzustellen und mit Farbschemata zu versehen.
